# Review and specify the editable Figma and Flutter UI of a cute couple app

Read design system and latest owner screenshot feedback. Translate preferences into exact UI changes: hierarchy, spacing, tokens, page states, motion map and reduced-motion variant. Deliver file-specific Flutter implementation plan or editable Figma component directions. Never treat a flattened image as an editable Figma file. Test on multiple screen sizes and real Vietnamese copy.
