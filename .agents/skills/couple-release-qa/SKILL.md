# Review quality gates and update project handoff

Read `AGENTS.md`, `PROJECT_STATE.md`, change diff and test evidence. Check Flutter analyze/tests, Spring tests/security, migrations, media permissions, UX screenshot proof, accessibility, secret scans, logs, cost controls. Mark PASS only when evidence exists; otherwise PARTIAL/FAIL. Update living handoff and decisions with commit SHA, tested commands, unresolved blockers and next TASK-ID. Production actions require approval.
